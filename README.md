# WaterMark
## Background:
One thing that has been on my mind for a while is how much water gets used when I use AI. If you don't know much about the relationship between water and AI, water helps cool down AI data centers. Although I try to minimize my use, I rely on it when I'm completely stuck on something. In these cases, I always wonder how many gallons of water I end up using during one short conversation. Then, I came up with this Chrome extension ! :D

## What this does
Calculates how many gallons of water is used up during AI usage.
